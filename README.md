# C++ Programming Fundamentals

Pamata C++ konsoles lietotņu un fundamentālu algoritmu kolekcija, kas aptver pirmā un otrā kursa studiju kursu tēmas.

## 🛠 Features & Topics Covered:
- **Control Structures:** `if / else`, `switch`, condition checks.
- **Loops:** `for`, `do-while` loops.
- **Arrays & Vectors:** `std::vector`, element searching (`min`, `max`), average calculation.
- **Strings:** `std::string` manipulation and palindrome checks.
- **Pointers & Memory:** Function parameters passing via pointers (`int*`).
